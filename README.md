# 📦 Симулятор ПВЗ (PVZ Simulator)

> **PVZ Simulator** — трёхмерный low-poly симулятор пункта выдачи заказов с видом от первого лица, созданный на движке **Unity 6.3 LTS (Universal Render Pipeline)**.

---

## 🎮 Игровой процесс и механики

* **Заказ партий товаров через ПК**: оператор заказывает коробки на рабочем компьютере, видит статус поставки и таймер приближения фуры в реальном времени.
* **Реалистичная логистика фуры**:
  * Фура подъезжает по улице, плавно выруливает и сдаёт задом к крыльцу по траектории Безье с выравниванием по вектору скорости.
  * Звуки зуммера заднего хода и пневматического сброса давления тормозов (*«Пш-ш-ш!»*), затухающая качка подвески.
  * Асимметричное открытие дверей и опускание аппарели (трапа) прямо на асфальт (-20°).
  * 15-секундный таймер-предупреждение при опустошении фуры.
  * **Секретная пасхалка «Безбилетник»**: если игрок остаётся внутри пустой фуры, грузовик увозит его со склада по улице, выдаёт всплывающую ачивку Steam **«Безбилетник»** со звуковым джинглом и возвращает игрока обратно в ПВЗ.
* **Складской учёт и ячейки**:
  * Стеллажи со слотами (`A1`–`A4`, `B1`–`B4`).
  * Физическое размещение коробок по ячейкам и автоматическая привязка к складской базе данных.
* **Обслуживание посетителей у стойки**:
  * Единый вход с улицы в клиентский зал.
  * Клиенты выстраиваются в очередь перед стойкой.
  * Номер заказа скрыт до момента сканирования сканером штрихкодов.
  * При сканировании запускается таймер скорости обслуживания и подсвечивается нужная ячейка на складе.
  * **Градация скорости и рейтинг**:
    * \(\le 15\) сек: **+1 очко рейтинга** (бонусная скорость).
    * 15–45 сек: **0 (нейтрально)**.
    * 45–60 сек: **-1 очко рейтинга**.
    * 60–120 сек: **-3 очка рейтинга**.
    * \(>120\) сек: **-5 очков рейтинга** (клиент ждёт до победного, не уходит сам).
* **Защита от очередей впустую**: клиенты приходят только если на складе физически есть посылки.

## 🕹 Управление

| Действие | Клавиши |
|---|---|
| **Перемещение** | `W`, `A`, `S`, `D` |
| **Обзор** | `Мышь` |
| **Взаимодействие** | `E` или `Левая кнопка мыши` (взять/поставить коробку, сесть за ПК, переключить табличку Open/Closed, отсканировать) |
| **Бросок коробки** | `Правая кнопка мыши` |
| **Выход из ПК / Меню** | `Esc` |

## 🛠 Технологии и архитектура

* **Движок**: Unity 6.3 LTS (6000.3.23f1) URP
* **Архитектура**:
  * `Assets/Scripts/Player/` — кинематический контроллер первого лица (`PlayerController.cs`).
  * `Assets/Scripts/Interactions/` — взаимодействие, удержание, размещение и броски (`PickupController.cs`).
  * `Assets/Scripts/Warehouse/` — менеджер склада, стеллажи и ячейки (`WarehouseManager.cs`, `WarehouseShelf.cs`, `WarehouseSlot.cs`).
  * `Assets/Scripts/Delivery/` — логистика грузовика, кривые Безье, звуки и анимации (`DeliveryTruck.cs`, `DeliveryManager.cs`).
  * `Assets/Scripts/Customers/` — ИИ клиентов, очередь, распознавание заказов и таймер (`CustomerAI.cs`, `CustomerQueueManager.cs`).
  * `Assets/Scripts/Counter/` — стойка выдачи, сканер штрихкодов и табличка Открыто/Закрыто (`CheckoutCounter.cs`).
  * `Assets/Scripts/Economy/` — касса и рейтинговая система (`EconomyManager.cs`, `RatingManager.cs`).
  * `Assets/Scripts/Computer/` — терминал и операционная система ПВЗ-ОС (`ComputerTerminal.cs`, `ComputerUI.cs`).
  * `Assets/Scripts/Editor/` — автогенератор сцены (`TestSceneBuilder.cs`).

## 🚀 Запуск проекта

1. Откройте проект в **Unity 6.3 LTS**.
2. В верхнем меню Unity выберите:
   ```text
   Tools -> PVZ -> Rebuild Test Room Scene
   ```
3. Нажмите кнопку **Play (▶)** в редакторе Unity.
